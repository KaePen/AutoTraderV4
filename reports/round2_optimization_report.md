# USDJPY トレードロジック最適化レポート (Round 2)

## 概要

2010-2025年 USDJPYフルバックテスト結果に基づくデータ駆動型パラメータ最適化。
Round 1（PR #258）の結果を詳細分析し、さらなる改善を実施（PR #259）。

## 実施変更一覧

### Round 1 (PR #258) - 基礎改善
| パラメータ | 変更前 | 変更後 | 根拠 |
|-----------|--------|--------|------|
| SL floor | 10 pips | 15 pips | SL<15の損失削減 |
| consensus_threshold | 5.0 | 7.0 | 低スコア帯の排除 |
| stagnation_exit | 240分 | 120分 | 停滞トレード早期撤退 |
| BE cushion | 0 pips | 3 pips | BE_HIT頻度低減 |
| trailing ATR | 2.0x | 2.5x | トレーリング幅最適化 |

### Round 2 (PR #259) - 品質フィルタ強化
| パラメータ | 変更前 | 変更後 | データ根拠 |
|-----------|--------|--------|-----------|
| SL floor | 15 pips | **20 pips** | 15-20帯が-1.16M損失 |
| consensus_threshold | 7.0 | **8.0** | score<8は全帯マイナス |
| penalty_cap | 0.8(実質無効) | **0.3** | penalty>0.3で-196K |
| trend_strength_max | なし | **0.8** | >0.8で-432K(50%WR) |

## 主要改善ポイント

### 1. SL_HIT損失の半減
- Round 1: 7,457件, -11,174,643
- Round 2: 3,702件, -5,516,659
- **改善幅: +5,657,984 (50.7%削減)**
- SL floor 20pips + 品質フィルタにより低品質エントリーを排除

### 2. TRENDレジームのプラス転換
- Round 1: -340,751 (48.9% WR)
- Round 2: **+980,369** (41.4% WR)
- トレンド強度上限フィルタ(0.8)が過度なトレンド追従を防止
- 勝率は下がったがPFが大幅改善

### 3. TIME exitの収益化
- Round 1: -221,272 (47.6% WR)
- Round 2: **+1,360,965** (70.7% WR)
- 高品質エントリーのみが保有され、時間経過でも利益を維持

### 4. 安定性の向上
- 黒字年: 14/16 → **16/16**
- 月間プラス率: 69.3% → **83.9%**
- 最大DD: 9.81% → **6.04%**
- 最悪年(2019): -66,354 → **+22,350**

## 今後の検討事項

1. **STAGNATION exit最適化**: 依然として-2.15Mの損失源。MFEベースの早期撤退条件の微調整で改善余地あり
2. **SL_HIT**: -5.5Mの損失はまだ大きい。SL幅のさらなる拡大（25pips）や動的SL（ATRベース）の検討
3. **部分利確比率の増加**: TP_1R/TP_2Rの利確比率を増やし、早期利益確定を強化する可能性
4. **セッション別フィルタ**: TOKYO session (-349K) の弱さに対するフィルタ追加
5. **CLIデフォルト値の統一**: run_backtest.py のCLIデフォルトとconfig値の不一致解消

## 実行コマンド

```bash
# Round 2 バックテスト再現
python scripts/run_backtest.py \
  --years 2010-2025 \
  --symbol USDJPY \
  --max-positions 3 \
  --risk-pct 0.02 \
  --max-lot-per-trade 2.0 \
  --max-total-exposure 5.0 \
  --data-dir data
```

## 結論

Round 2最適化により、**全16年黒字**を達成し、リスク調整後リターン(SR 3.23)と最大ドローダウン(6.04%)が大幅に改善された。特にTRENDレジームのプラス転換とSL損失の半減が顕著な成果である。
