# Early Profit Guard (EPG) 評価レポート

## 概要

USDJPY M1 8TF バックテスト（2020-2025、6年間）でEarly Profit Guard機能の効果を検証。

EPG = センチメント悪化（反対スコア優勢）+ 小利益（MFE 0.05-0.30R）時に早期撤退する機能。

## テスト設定

| 項目 | Baseline | EPG有効 |
|------|----------|---------|
| early_profit_guard_enabled | OFF (default) | ON |
| min_mfe_r | - | 0.05 |
| min_r | - | 0.0 |
| max_r | - | 0.30 |
| score_diff | - | 1.0 |
| min_opp_score | - | 4.0 |
| min_hold_minutes | - | 5.0 |

## 結果サマリー

| 指標 | Baseline | EPG有効 | 差分 |
|------|----------|---------|------|
| 総取引数 | 8,603 | 8,754 | +151 (+1.8%) |
| 勝率 | 62.6% | 63.2% | **+0.6pp** |
| 非敗率 | 79.7% | 80.1% | +0.4pp |
| PF | 1.76 | 1.79 | **+0.03** |
| 純利益 | +1,528,621 | +1,601,029 | **+72,408 (+4.7%)** |
| 最大DD | 1.33% | 1.33% | 0 |
| Sharpe | 5.13 | 5.31 | **+0.18** |
| 年間平均収益率 | 25.5% | 26.7% | **+1.2pp** |
| 月間平均収益率 | 1.88% | 1.95% | +0.07pp |

## 分析

1. **全年で改善**: 6年全てでEPG有効が上回っている
2. **直近ほど効果大**: 2023-2025で+17K〜+19K/年の改善
3. **DDは同等**: 最大ドローダウンは両者1.33%で同水準
4. **取引数微増**: EPGにより早期撤退→再エントリーで+151取引
5. **Sharpe改善**: 5.13→5.31（+0.18）、リスク調整後リターンが向上

## 判定

**ADOPT (採用推奨)**

- 全年で利益改善（+72K/6年、年平均+12K）
- WR +0.6pp, PF +0.03, Sharpe +0.18 の安定的改善
- DD悪化なし
- 保守的な7条件AND門で過剰早期退出リスクを抑制
- very_early_exitの教訓（-935K）を踏まえた慎重な設計

## 実行コマンド

```bash
# Baseline
python scripts/run_backtest.py --symbol USDJPY --years 2020-2025 --data-dir data

# EPG有効
python scripts/run_backtest.py --symbol USDJPY --years 2020-2025 --data-dir data --pm-early-profit-guard-enabled
```
