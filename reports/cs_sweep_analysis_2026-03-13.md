## 4. キーファインディング

### 4-1. WR への影響

**CS 引き上げは WR を一貫して改善するが、改善幅は限定的**:
- 全ペアで CS9.5 → CS12 へ引き上げると **+0.9〜+2.7pp** の WR 改善。
- CS11 → CS12 の追加改善は **0〜1pp 程度**に収縮。
- CS13 まで引き上げても USDJPY の WR はほぼ頭打ち (78.02%、CS11 と同値)。
- **WR 改善の限界収益は CS11 で概ね到達**する。

### 4-2. トレード数コスト

CS を 1.0 引き上げるごとのトレード数減少率:

| ペア | CS9.5→CS11 | CS11→CS12 | 総コスト (9.5→12) |
|------|-----------|-----------|-----------------|
| USDJPY | -12% (9.5→10: -5%, 10→11: -7%) | -14% | -24% |
| GBPJPY | +1% (増加) | -5% | -4% |
| AUDJPY | +11% (増加) | -9% | +1% |
| CADJPY | -9% | -9% | -17% |
| CHFJPY | +18% (増加) | -8% | +9% |

**異常値**: GBPJPY、AUDJPY、CHFJPY では CS9.5→CS11 でトレード数が*増加*している。
これは TSM=0.85 との組み合わせ効果によるフィルタリング相互作用の可能性がある。

### 4-3. 利益への影響

- **USDJPY**: CS10 が最大利益。CS11 以降は急速に減少 (CS13 で BL 比 -38%)。
- **GBPJPY/AUDJPY/CHFJPY**: CS11 が最大利益で BL 比 +5〜+23%。
- **CADJPY**: 全テストで BL を下回る。CS12 は DD・PF 改善に特化した選択肢。

### 4-4. DD・PF 改善効果

- USDJPY: CS 引き上げで DD が 7% → 4.86% に大幅改善。
- CADJPY: CS12 で DD=3.74%、PF=2.414 — リスク調整後パフォーマンスが顕著に向上。
- AUDJPY: CS11 で DD が悪化 (4.20% → 5.95%)、CS12 で部分回復 (4.83%)。

## 6. 結論

1. **CS 引き上げで WR は改善するが、効果は CS11 で概ね飽和**。CS13 まで上げても追加 WR 改善はほぼなく、トレード数と利益を大きく損なう。

2. **利益最大化の観点では CS10〜CS11 が最適帯**。USDJPY は CS10、その他 JPY ペアは CS11 が利益ピーク。

3. **DD・リスク管理重視なら CS12**。CADJPY の DD=3.74%/PF=2.414 は特に顕著で、DD 圧縮目的なら CS12 は有力候補。

4. **USDJPY のみ CS10 を推奨**。他ペアより1段低い閾値でも利益・WR ともに優位を維持し、TSM=0.85 との組み合わせで月次+ 100% を達成している。

5. **GBPJPY/AUDJPY/CHFJPY の CS11 トレード増加は精査要**。フィルタ相互作用による意図しない緩和の可能性があり、シグナル品質の内訳確認を推奨。
