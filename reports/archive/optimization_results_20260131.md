## シグナル生成ロジック

### 買い条件（シグナル数 >= 3）

1. **RSI条件**
   - RSI < 30: +2ポイント
   - RSI < 35: +1ポイント

2. **MACD条件**
   - MACD > シグナル: +1ポイント
   - MACD > 0 かつ上昇: 追加+1ポイント

3. **トレンド条件**
   - 終値 > SMA20 > SMA50: +1ポイント

4. **ADX条件**
   - ADX > 25: 優勢方向に+1ポイント

5. **MTFボーナス**
   - H4上昇トレンド確認時: +2ポイント

### 売り条件（シグナル数 >= 3）

1. **RSI条件**
   - RSI > 70: +2ポイント
   - RSI > 65: +1ポイント

2. **MACD条件**
   - MACD < シグナル: +1ポイント
   - MACD < 0 かつ下落: 追加+1ポイント

3. **トレンド条件**
   - 終値 < SMA20 < SMA50: +1ポイント

4. **ADX条件**
   - ADX > 25: 優勢方向に+1ポイント

5. **MTFボーナス**
   - H4下降トレンド確認時: +2ポイント

### エントリー条件

- シグナルポイント >= 3
- 買い/売りの差分 > 1（シグナルマージン）
- ADX >= 15（トレンド存在確認）
- 前回シグナルから4時間以上経過（クールダウン）

### リスク管理

- SL: 2.0 × ATR
- TP: 3.0 × ATR
- リスクリワード比: 1:1.5
- 最大ポジション: 1
- ロット: 0.5（5万通貨）

## 処理速度について

V3との比較:
- **V4**: polars + Parquet形式でデータ読み込み → 0.04秒（99,206レコード）
- **V3**: pandas CSVで読み込み → 数秒以上

処理速度の向上はpolarsの使用によるもので、シミュレーションロジックに問題はありません。
