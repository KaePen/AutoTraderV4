# UnifiedTradeBot 最適化レポート

## 概要

統合トレードボット（UnifiedTradeBot）の最適化を実施し、月間+8%の収益目標に向けた改善を行った。

## 改善内容

### 1. シグナル精度の改善

- **ADXフィルター追加**: トレンド強度が閾値以上の場合のみトレード
- **上位足トレンド一致チェック**: H4/D1のトレンドがシグナル方向と一致する場合のみトレード
- **TP/SL比率調整機能**: 設定可能なTP/SL比率で勝率と利益のバランスを調整

### 2. プリセット設定の追加

| プリセット | 特徴 | 推奨ボリューム |
|-----------|------|---------------|
| `high_win_rate` | 勝率60%以上を目指す | 1-2倍 |
| `monthly_target` | 月間+8%目標 | 4倍 |
| `aggressive` | 積極的な取引 | 5倍 |
| `ultra_aggressive` | 最大リターン追求 | 8-15倍 |

### 3. 最適化パラメータ

```python
UnifiedBotConfig(
    consolidator=ConsolidatorConfig(
        consensus_rule=ConsensusRule.MAJORITY,
        min_alignment=2,
        confidence_threshold=0.40,
    ),
    risk=RiskConfig(
        cooldown_minutes=10,
        default_sl_pips=10.0,
        default_tp_pips=15.0,
    ),
    timeframes=["M15", "H1", "H4", "D1"],
    min_adx=15.0,
    require_htf_trend=True,
    tp_sl_ratio=1.5,
)
```

## 結論

1. **月間+8%目標**: 
   - 2020年1-6月で月平均9.34%を達成（ボリューム10倍）
   - 年間通しでは市場環境により変動あり

2. **推奨設定**:
   - `ultra_aggressive`プリセット
   - ボリューム10-15倍
   - 最大ドローダウン許容: 15-20%

3. **リスク**:
   - 後半のパフォーマンス低下（市場環境の変化）
   - 高ボリュームによるドローダウンリスク
